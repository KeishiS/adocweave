AdocWeave command-line interface

Usage:
  adocweave <COMMAND> [ARGUMENTS]

Commands:
  convert  Convert an AsciiDoc document to HTML
  preview  Serve a live document preview
  check    Check AsciiDoc documents
  format   Format AsciiDoc documents
  symbols  Print document symbols as JSON
  rules    List diagnostic rules
  config show  Print the resolved project configuration as JSON
  completion SHELL  Print a shell completion script
  help     Print root help

Options:
  -V, --version [--json]  Print version
  -h, --help  Print help
