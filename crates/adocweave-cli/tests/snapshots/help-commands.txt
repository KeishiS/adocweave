=== convert ===
Usage:
  adocweave convert [OPTIONS] [FILE]

Arguments:
  FILE  Input file; omit or use - for standard input

Options:
  --complete  Output a complete HTML document
  --css FILE  Embed CSS from FILE; repeatable
  --css-url URL  Link an allowed CSS URL; repeatable
  --include  Process local includes even if disabled by configuration
  --no-include  Leave include directives unresolved
  --stdin-base DIR  Resolve standard-input includes from DIR
  --allow-root DIR  Permit includes below DIR; repeatable
  --config FILE  Use the specified project configuration
  --no-config  Disable project configuration discovery
  --color WHEN  Color output: auto, always, or never (default: auto)
  -h, --help  Print help

Example:
  adocweave convert --complete manual.adoc
=== preview ===
Usage:
  adocweave preview [OPTIONS] FILE

Arguments:
  FILE  AsciiDoc file to preview; standard input and symbolic links are not supported

Options:
  --bind ADDRESS  Listen address (default: 127.0.0.1)
  --port PORT  Listen port (default: 4000)
  --debounce-ms MILLISECONDS  Rebuild debounce interval (default: 100)
  --allow-external  Permit an explicitly selected non-loopback address
  --include  Process local includes even if disabled by configuration
  --no-include  Leave include directives unresolved
  --allow-root DIR  Permit includes below DIR; repeatable
  --css FILE  Embed CSS from FILE; repeatable
  --css-url URL  Link an allowed CSS URL; repeatable
  --config FILE  Use the specified project configuration
  --no-config  Disable project configuration discovery
  --color WHEN  Color output: auto, always, or never (default: auto)
  -h, --help  Print help

Security:
  A non-loopback address requires --allow-external.
  The server does not provide authentication or TLS encryption.

Example:
  adocweave preview --port 8080 manual.adoc
=== check ===
Usage:
  adocweave check [OPTIONS] [FILE...]

Arguments:
  FILE  Input file or directory; omit or use - for standard input

Options:
  --format FORMAT  Output format: human, json, github, or sarif (default: human)
  --fail-on LEVEL  Fail on error, warning, or never (default: error)
  --summary  Print counts to standard error
  --fix  Write fixes that are always safe to apply
  --diff  Print changes as a unified diff
  --enable-rule CODE  Enable an opt-in rule; repeatable
  --glob PATTERN  Add matching files; repeatable
  --project-root DIR  Check local file targets below DIR
  --include  Process local includes even if disabled by configuration
  --no-include  Leave include directives unresolved
  --stdin-base DIR  Resolve standard-input includes from DIR
  --allow-root DIR  Permit includes below DIR; repeatable
  --config FILE  Use the specified project configuration
  --no-config  Disable project configuration discovery
  --color WHEN  Color output: auto, always, or never (default: auto)
  -h, --help  Print help

Examples:
  adocweave check --fail-on warning docs
  adocweave check --format sarif docs > adocweave.sarif
  adocweave check --fix docs
  adocweave check --fix --diff docs
