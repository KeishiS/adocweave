= アーキテクチャ

この文書は、AdocWeaveを構成する各コンポーネントの責務と依存方向の正本です。公開APIと対応範囲は
xref:core-profile.adoc[コアの対応範囲]、文法はxref:grammar.adoc[文法の詳細]、
利用側アプリの実行順序はxref:server-execution.adoc[利用側アプリの実行仕様]を参照してください。

[#component-boundaries]
== コンポーネントの責務と依存方向

[source,text]
----
VS Code・Zed ──LSP──> adocweave lsp
ブラウザークライアント ──> Web Worker ──> adocweave-wasm ──> adocweave
textlint ──> adocweave-textlint ──> adocweave

adocweave-cli ──> adocweave-lsp, adocweave-config, adocweave-host, adocweave-workspace, adocweave
adocweave-lsp ──> adocweave-config, adocweave-host, adocweave-workspace, adocweave
adocweave-project ──> adocweave-config, adocweave-host, adocweave
adocweave-config ──> adocweave-host, adocweave-workspace, adocweave
adocweave-workspace ──> adocweave
----

矢印は利用する側から利用される側へ向きます。下位コンポーネントは上位のプロトコル、実行環境または
製品固有の型へ依存しません。

[cols="2,5",options="header"]
|===
|コンポーネント |所有する責務

|``adocweave``
|I/Oに依存しない構文解析、意味情報、診断、整形、出力および問い合わせ

|``adocweave-host``
|ローカルファイルの読込権限、競合に耐えるパス検査および資源使用量の計測

|``adocweave-workspace``
|ディスク上のリソース、開いている文書、世代、依存関係およびI/Oに依存しない再開可能な前処理

|``adocweave-config``
|Rustの設定型から生成するスキーマ、設定の探索と読込、および処理上限の解決

|``adocweave-project``
|一回のプロジェクト処理で所有する全解析対象、設定の指定と上書き、検証済みのファイル読込権限、
処理上限および対象別の結果を表す要求・結果型

|``adocweave-cli``
|``adocweave``のコマンド、標準入出力、ファイル操作、処理の調停および終了状態への変換

|``adocweave-lsp`` crate
|``adocweave lsp``から呼び出すLSPの通信、URIと位置の変換、通知順序、並行実行およびクライアントへの結果公開

|``adocweave-wasm``
|WebAssemblyの要求・応答の検証と、公開する通信型とコア型の相互変換

|``adocweave-textlint``
|解析結果からtextlint用TxtASTへの変換と、コア解析およびTxtAST変換をNode.jsへ公開する
WebAssemblyインターフェイス

|ブラウザークライアントとWeb Worker
|Promiseと取消を含む公開入口、Workerの生存期間およびWebAssemblyの隔離

|VS Code拡張とZed拡張
|言語登録、基本色付けおよびLanguage Serverプロセスの起動。文書解析は所有しません。
|===

crateとpackageの正確な構成、依存先および版は各manifestを基準とします。この図は実装の直接依存を示します。
配布成果物と公開方法はxref:release-distribution.adoc[配布仕様]を基準とし、この文書へ複製しません。

[#single-analysis]
== 単一解析

入力は一度解析し、同じ版の解析結果を整形、診断、HTML、Language Serverおよび利用側アプリで共有します。
利用側ごとにソースを再解析したり、見出し、参照または文書構造を再導出したりしません。

構文層は元のbyte列、空白、不完全な入力および回復地点を保持します。意味層は見出し、段落、表、参照、
属性などを出力形式に依存しない値として表します。HTMLやエディタ固有の規則はParserへ持ち込みません。
具体的な認識規則と回復結果はxref:grammar.adoc[文法の詳細]を基準とします。

[#host-boundary]
== 利用側アプリとの分担

コアはファイルシステム、ネットワーク、データベース、環境変数および非同期の実行環境へ直接アクセスしません。
利用側アプリは外部リソースを取得して権限と上限を確認し、一回の処理中に変化しないスナップショットとして渡します。

ローカルファイルの安全性は``adocweave-host``、保持中のリソースと解析世代は``adocweave-workspace``、
設定と上限の解決は``adocweave-config``が所有します。CLIとLanguage Serverはこれらを組み合わせますが、
同じパス検査、予算計測またはinclude規則を独自に実装しません。

取得、取消しまたは解析に失敗した候補状態は公開状態へ反映しません。利用側アプリは結果を公開する直前に
入力の版と設定を再確認し、古い結果を破棄します。詳しい実行順序と失敗時保証は
xref:server-execution.adoc[利用側アプリの実行仕様]を基準とします。Language Server固有の通知と要求は
xref:language-server.adoc[Language Serverの実行仕様]を基準とします。

アプリ固有のID、データベーススキーマ、アクセス制御および検索用メタデータは、標準の意味情報へ混在させません。
利用側アプリは採用済みの解析結果から独自情報を検証・取得します。拡張方法は
xref:extensions.adoc[利用側アプリの拡張]を参照してください。

[#trust-boundary]
== 純粋性と安全性

同じ入力、設定、外部リソースのスナップショットおよびpackage版からは、同じ解析結果と出力を生成します。
時刻、乱数、ファイルシステムの列挙順およびmapの挿入順を結果へ反映しません。

文書入力、外部リソースおよび利用側アプリが返すURLを信頼済みのHTMLとして扱いません。HTML出力では
要素、属性、classおよびURLを許可集合へ制限します。出力規則は
xref:html-contract.adoc[HTML出力の仕様]を基準とします。

処理上限は構造要素や診断を全件生成する前に適用します。CPU処理、外部I/O、実行枠の待機および
クライアントとの通信中に共有状態のロックを保持しません。

[#change-invariants]
== 変更時の不変条件

実装変更では次の条件を維持します。

* 出力形式、実行環境または利用側アプリごとのParserの複製禁止
* 構文追加時における構文情報、意味情報、診断、整形、出力および代表アダプターの同時確認
* 未処理要素の明示と、回復処理の入力上での前進
* ルート文書とinclude文書における前処理規則、上限およびソースマップの共通化
* 外部I/Oを利用側アプリ、決定的な解析と変換をコアが担う責務分離
* 同じ入力スナップショットに対するnativeとWebAssemblyの意味情報および出力の一致

ファイル数や行数だけを理由に層を追加しません。分割する場合は、解析、出力、プロトコル変換、実行制御または
外部I/Oのいずれを所有するかを先に定めます。
