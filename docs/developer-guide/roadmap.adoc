= 今後の予定

この文書では、現在進行中の作業と着手を予定している作業の方向を示します。実施時期や公開日を
約束するものではありません。各作業の詳しい内容、依存関係および完了条件は、リンク先の
GitHub Issueを参照してください。

完了した作業の経緯はIssue、バージョンごとの変更は
https://github.com/KeishiS/adocweave/releases[GitHub Releases]のRelease Notesに記録します。
このページには完了したmilestoneの履歴を残しません。

以下は、着手するかどうかの判断が先に必要な項目です。判断の材料が揃うまで実装へ進みません。

== 保留中の対話的な確認環境

公開済みのBrowser APIとHTML出力の仕様を利用し、Webブラウザーだけで文書を試せる環境を提供する案を
保留しています。

* https://github.com/KeishiS/adocweave/issues/84[公式Playground]

公式Playgroundの公開には、配信先、公開URL、公開作業を行う権限および問題発生時に以前の状態へ戻す
権限を決める必要があります。これらが決まるまで実装済みのローカルプレビューとは分離し、
製品バージョンの更新やほかの機能を公開するための前提にはしません。

== 条件付き候補

次の作業は具体的な需要や運用上の問題が確認されるまで着手しません。

* https://github.com/KeishiS/adocweave/issues/33[単体CLIのlocal resource profile評価]
* https://github.com/KeishiS/adocweave/issues/34[RenovateによるNix依存更新の評価]

単体CLIのlocal resource profileは、相対resourceを解決する需要が確認された場合に再評価します。
RenovateによるNix依存更新は、手動更新が継続的な負担となった場合に再評価します。

== 進行中の公開経路

textlint用Processor、WebAssembly packageおよびCLIをnpm Registryへ段階的に公開する準備を進めています。
公開はGitHub Releaseの公開後に専用jobだけが行い、Releaseで検証した成果物と同じbyte列を送ります。
npm向けに構築し直しません。

* https://github.com/KeishiS/adocweave/issues/83[npm Registryへの段階的な公開]

公開はpackageごとに段階を分けます。npmはpackageが実在しないと公開元の登録を設定できないため、
最初のpackageで公開、復旧および公開後検査の手順を確認してから残りへ広げます。

* https://github.com/KeishiS/adocweave/issues/714[公開方針の文書への反映]
* https://github.com/KeishiS/adocweave/issues/715[公開基盤と復旧手順]
* https://github.com/KeishiS/adocweave/issues/716[textlint用Processorの公開]
* https://github.com/KeishiS/adocweave/issues/717[WebAssembly packageの公開]
* https://github.com/KeishiS/adocweave/issues/718[CLIの公開]

== 実施しない公開経路

Visual Studio Marketplace、Zed Extension Gallery、crates.ioおよびOSのpackage managerへの
登録・公開は行いません。次のIssueは実装候補ではなく、この判断と過去の検討内容を残す記録として保留します。

* https://github.com/KeishiS/adocweave/issues/82[公式extension registry（Open VSX以外）]
* https://github.com/KeishiS/adocweave/issues/86[Homebrew・WinGet・Scoopの評価]
