= 対応しているAsciiDocの書式

AsciiDocの仕様すべてを実装しているわけではありません。
他の実装との差は xref:compatibility.adoc[AsciiDocとの互換性]を参照してください。
文法の厳密な定義は xref:../developer-guide/grammar.adoc[文法の詳細]にあります。

== 構文一覧

この節では、各構文を識別するための最小限の記述例を示します。
対応範囲と制約の詳細は、後述する表を参照してください。

=== 文書構造

==== 文書ヘッダ

空行を挟まずファイル先頭に記述した、文書タイトル、著者行、改訂行および文書属性の並びです。
最初の空行で文書ヘッダが終了し、その次の内容から本文が始まります。

[source,asciidoc]
----
= 文書タイトル
Jane Doe <jane@example.org>
v0.1, 2026-08-29: 初版
:doctype: article

ここから本文です。
----

著者行は文書タイトルの直後、改訂行は著者行の直後に置きます。
著者行と改訂行を省略する場合は、文書タイトルの直後に文書属性を記述できます。

著者と改訂の情報を文書属性として個別に記述することもできます。
ただし、この形式は一般の文書属性として扱われ、
著者行と改訂行から得られる型付きの著者・改訂情報にはなりません。

[source,asciidoc]
----
= 文書タイトル
:author: Jane Doe
:email: jane@example.org
:revnumber: v0.1
:revdate: 2026-08-29
:revremark: 初版
----

==== Preamble

文書ヘッダの後から最初のセクションまでに置かれる導入本文です。
``book`` doctypeで xref:#book-part[book part]を使う場合は、最初のbook partまでがPreambleになります。
文書ヘッダがない場合はファイル先頭から始まり、
セクションもbook partもない場合は残りの本文全体がPreambleになります。
``[discrete]``または``[float]``を付けた見出しはPreambleを終了しません。
文書の概要や目的などを記述する導入部分として利用できます。

[source,asciidoc]
----
= 文書タイトル
Jane Doe <jane@example.org>
:doctype: article

ここがPreambleです。
文書の概要や目的などを記述します。

== 最初のセクション

ここからセクションの本文です。
----

==== 文書タイトルとセクション見出し

ファイル先頭の1個の``=``マーカーは文書タイトルです。
2個から6個のマーカーは、レベル1から5のセクション見出しです。
``[discrete]``または``[float]``を付けると、セクション階層へ含めない独立した見出しになります。

[source,asciidoc]
----
= 文書タイトル

== セクション

=== 下位のセクション

[discrete]
=== セクション階層へ含めない見出し
----

[#book-part]
==== Book part

book partは、``book`` doctypeで複数の章をまとめる構造上の区分であり、導入本文ではありません。
文書タイトルと同じく1個の``=``マーカーで記述します。次の``第1部``がbook part、``第1章``がその中の
セクションです。

[source,asciidoc]
----
= 書籍タイトル
:doctype: book

= 第1部

== 第1章
----

==== 段落

空行を含まず連続する行を1つの段落として扱います。

[source,asciidoc]
----
これが1つの段落になります。
改行しても段落のまとまりが壊れることはありません。

前の段落から空行を挟んでいるため、これは別の段落となります。
----

=== ブロック構文

==== 文書属性

文書属性は``:<名前>: <値>``で定義し、``:<名前>!:``で解除します。
定義した位置より後では``{<名前>}``で値を参照できます。

[source,asciidoc]
----
:product-name: AdocWeave
:description: 長い説明を \
複数の行に分けて記述します。

{product-name}を使用します。
{description}

:product-name!:
----

属性値を複数行に分ける場合は、最後の行を除く各行の末尾へ空白と``\``を置きます。
これにより1行の値として扱われます。

==== ブロックメタデータ

ブロックメタデータはブロックに対して、タイトル、ID、roleおよびoptionなどを指定する情報です。
空行を挟まず対象ブロックの直前に置きます。

[source,asciidoc]
----
.設定例
[#configuration.example.wide%collapsible%open]
====
ここがブロックの内容です。
====
----

この例の記号は、次の情報を表します。

[cols="2,2,3",options="header"]
|===
|記述 |種類 |意味

|``.設定例``
|ブロックタイトル
|ブロックに表示するタイトルです。

|``#configuration``
|ID
|ブロックを参照するときに使う一意の名前です。

|``.example.wide``
|role
|ブロックへ``example``と``wide``の2個のroleを付けます。許可されたroleはHTMLのclassなどに利用できます。

|``%collapsible%open``
|option
|``collapsible``でexample blockを折り畳み可能にし、``open``で初期状態を展開済みにします。

|``====``
|example blockの区切り
|メタデータではなく、メタデータを適用するブロック本体の開始と終了を示します。
|===

``[#configuration.example.wide%collapsible%open]``は1つの属性リストです。
この中では、``#``がID、``.``がrole、``%``がoptionの開始を示します。
複数のroleまたはoptionを指定するときは、それぞれの記号を繰り返します。
名前付き属性で書く場合は以下のように、roleを空白、optionをカンマで区切ります。

[source,asciidoc]
----
[role="example wide",options="collapsible,open"]
====
ここがブロックの内容です。
====
----

==== 明示アンカー

アンカーは、文書内外から参照できる名前付きの参照先です。タイトル、roleおよびoptionとは目的が異なりますが、
ブロックの直前に置いたアンカーは、そのブロックへIDと表示文字列を与えるブロックメタデータとして扱われます。
セクション見出しには見出しの文字列からIDが自動生成されます。明示アンカーは、自動生成に依存せずIDを
指定したい場合に使います。

[source,asciidoc]
----
[[another-id,別の参照先]]
別の段落です。

<<another-id>>を参照します。
----

``another-id``は参照に使うID、``別の参照先``は表示文字列です。
前節で例示した``[#configuration...]``の``#configuration``もブロックへIDを与えるため、
そのブロックをアンカーとして参照できます。

==== インデントしたリテラル段落

行頭を空白またはタブで字下げすると、書式を適用しないリテラル段落になります。

[source,asciidoc]
----
  この行はリテラル段落です。
  *強調*などのインライン書式も適用しません。
----

==== 区切り線と改ページ

``'''``は区切り線、``<<<``は改ページを表します。

[source,asciidoc]
----
前半の本文です。

'''

後半の本文です。

<<<
----

==== 区切り付きブロック

ブロックの種類に対応する区切りで内容を囲みます。次はexample、listingおよびliteral blockの例です。

[source,asciidoc]
-----
.例のタイトル
====
example blockの内容です。
====

----
listing blockの内容です。
----

....
literal blockの内容です。
....
-----

comment（``////``）、open（``--``）、sidebar（``****``）、pass（``++++``）、quote（``____``）および
tableにも対応します。各ブロックで利用できる属性と変換結果は、後述する対応表を参照してください。

==== ソースブロック

listing blockへ``source`` styleと言語を指定します。言語を先頭の属性として指定する短縮形も使えます。

[source,asciidoc]
-----
[source,rust]
----
fn main() {
    println!("Hello");
}
----

[,javascript]
----
console.log("Hello");
----
-----

==== Admonition

短い注意書きは段落形式、複数のブロックを含む注意書きはブロック形式で記述します。

[source,asciidoc]
----
NOTE: 補足情報です。

[WARNING]
====
この操作を行う前にバックアップを作成してください。
====
----

==== Quoteとverse

``quote``は引用、``verse``は改行を保持する詩句などを表します。

[source,asciidoc]
----
[quote,著者名,出典]
____
引用文です。
____

[verse,著者名,出典]
____
1行目です。
2行目です。
____
----

==== 表

標準の表では``|``でcellを区切ります。

[source,asciidoc]
----
[cols="1,2",options="header"]
|===
|項目 |説明

|状態
|対応状況を表します。
|===
----

CSV、DSV、TSVや、cellの結合、配置およびAsciiDoc形式のcellにも対応します。詳細は後述する対応表を
参照してください。

==== リスト

``*``は順序なしリスト、``.``は順序付きリスト、``::``は定義リストを表します。
マーカーを重ねるとリストを入れ子にできます。

[source,asciidoc]
----
* 項目1
** 入れ子の項目
* 項目2

. 手順1
. 手順2

用語:: 用語の説明です。
----

==== LaTeX STEMブロック

``stem``または``latexmath`` styleを付けたpass blockへLaTeX数式を記述します。

[source,asciidoc]
----
[stem]
++++
E = mc^2
++++
----

==== 空行と未知のブロック構文

空白またはタブだけの行も空行として扱い、段落や文書ヘッダなどを終了させます。
認識できない構文は``permissive``モードでは内容を保持しますが、その構文としての意味や変換結果は保証しません。

==== 前処理ディレクティブ

``include``で別の文書を読み込み、``ifdef``、`ifndef`および``ifeval``で条件に応じて行を選択します。
前処理を有効にしない場合は評価せず、そのままの文字列として保持します。

[source,asciidoc]
----
include::compatibility.adoc[]

ifdef::web[]
Web向けの説明です。
endif::[]
----

=== インライン構文

==== 強調、斜体および等幅

単語の区切りにある単一マーカーと、前後の文字に依存しない二重マーカーを使えます。

[source,asciidoc]
----
*強調*、_斜体_、`等幅`

単語**内の強調**、単語__内の斜体__、単語``内の等幅``

*_入れ子にした書式_*
----

書式は空行を越えませんが、同じ段落内であれば改行をまたいで記述できます。
閉じていない書式は開始記号をテキストとして保持し、問題を報告します。

==== Hard line break

行末へ空白と``+``を置くと、段落内で明示的に改行します。

[source,asciidoc]
----
1行目です。 +
2行目です。
----

==== 文書属性参照

``{名前}``は、その位置で有効な文書属性の値を表示します。

[source,asciidoc]
----
:name: AdocWeave

使用するツールは{name}です。
----

counter参照は、名前を付けたカウンタの値を文書内で順に進める特殊な文書属性参照です。
値を指定せずに初めて参照すると``1``から始まります。
数値は1ずつ増え、英字1文字は次の英字へ進みます。``z``の次は``aa``です。

[cols="2,3",options="header"]
|===
|記法 |動作

|``{counter:name}``
|カウンタ``name``を1進め、進めた値を表示します。未定義の場合は``1``を設定して表示します。

|``{counter:name:start}``
|未定義のカウンタを``start``から開始して表示します。``start``には数値または英字1文字を指定できます。

|``{counter2:name}``
|カウンタ``name``を1進めますが、その位置には値を表示しません。

|``{name}``
|現在の値を進めずに表示します。
|===

[source,asciidoc]
----
項目{counter:item}、項目{counter:item}

{counter2:item}この行ではカウンタだけを進めます。
現在の項目番号は{item}です。

{counter:chapter:5}章、{counter:chapter}章
付録{counter:appendix:a}、付録{counter:appendix}
----

==== URLとxref

URLは単独または表示文字列付きで記述できます。``xref``は同じ文書または別の文書の参照先を表します。

[source,asciidoc]
----
https://example.org/
https://example.org/[ウェブサイト]

[#target]
== 参照先

<<target,参照先へ移動>>
xref:#target[参照先へ移動]
xref:another-document.adoc#target[別の文書へ移動]
----

==== インラインSTEM

``stem:[...]``または``latexmath:[...]``へLaTeX数式を記述します。

[source,asciidoc]
----
質量とエネルギーの関係はstem:[E = mc^2]です。
----

==== 標準macroとmedia

macroは``名前:target[属性]``の形で記述します。次はfootnote、引用、索引、mediaおよびUI macroの例です。

[source,asciidoc]
----
本文に脚注を付けます。footnote:[脚注の本文です。]

cite:[smith2024]
indexterm:[構文,インライン]

image::images/example.png[説明,width=320]
icon:warning[警告]
audio::audio/example.ogg[]
video::video/example.webm[]

kbd:[Ctrl+C]、btn:[保存]、menu:ファイル[保存]
----

画像、アイコン、音声および動画の取得と安全なURLへの解決は、利用側アプリが行います。

==== ハイライト、下付き、上付きおよび組版用引用符

[source,asciidoc]
----
#ハイライト#、H~2~O、x^2^、"`二重引用符`"、'`一重引用符`'
----

==== インラインpassthrough

``+...+``、``++...++``、``+++...+++``または``pass:[...]``で囲んだ内容には、
通常のインライン置換を適用しません。HTMLとして実行せず、安全なテキストとして出力します。

[source,asciidoc]
----
pass:[*このアスタリスクは強調になりません*]
+++<strong>HTMLとしては実行しません</strong>+++
----

==== バックスラッシュエスケープ

バックスラッシュを構文の前に置くと、直後の記号を構文として解釈しないようにします。

[source,asciidoc]
----
\*このアスタリスクは強調になりません*
\{name}は文書属性参照になりません。
----

== 対応するブロック構文

以下の2つの表の``状態``項目は、各構文の対応状況を表します。
``対応``となっているものは構文を認識し、必要な変換、問題表示、整形またはエディタ機能を提供します。
``保持``となっているものは、内容を失わず読み込めますが、書式としての意味付けや変換は行いません。
``部分対応``となっているものは、説明した範囲に限って対応します。``問題報告``となっているものは、問題箇所を
テキストとして保持し、問題を報告したうえで解析を続けます。``構文対応``となっているものは構文を認識しますが、出力には利用側アプリによる
解決が必要です。HTML出力では保持したテキストをエスケープします。``未対応``のものについては動作を保証していません。
