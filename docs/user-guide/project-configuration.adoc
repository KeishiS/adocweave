= プロジェクト設定

AdocWeaveのCLIとLanguage Serverは、共通の設定ファイル``.adocweave.toml``を使用します。
最小の設定は次のとおりです。

..adocweave.toml
[source,toml]
----
schema-version = 2
----

[#configuration-selection]
== 設定ファイルの選択

AdocWeaveは処理対象のディレクトリから親ディレクトリへ設定ファイルを探し、最も近い1件を使用します。
複数のファイルを処理する場合は、ファイルごとに設定を選びます。

CLIではコマンドを実行したディレクトリ、Language Serverではエディタで開いたワークスペースフォルダまでを
探索範囲とします。範囲外の設定をCLIで使用する場合は``--config FILE``を指定してください。

設定の継承、環境変数とチルダの展開、外部ファイルの読み込みおよびネットワークアクセスは行いません。
設定ファイルは1 MiBまでです。不明な項目、未対応の``schema-version``および許容範囲外の値はエラーになります。

設定内の相対パスは、設定ファイルがあるディレクトリを基準にします。パスの区切りには``/``を使用します。
絶対パス、ドライブ名、``\``および親ディレクトリへ移動する``..``は指定できません。

設定ファイルによって、ワークスペース外のファイルを読み込めるようにはなりません。CLIで外部のファイルを
使用する場合は、用途に応じて``--allow-root``、``--project-root``または``--css``を指定してください。

[#project-configuration-example]
== 設定例

[source,toml]
----
schema-version = 2

[analysis]
syntax-mode = "strict"

[analysis.attributes.release]
value = "draft"

[analysis.attributes.private]
unset = true

[lint.rules.macro-boundary]
enabled = true
severity = "error"

[lint]
max-line-length = 100
max-consecutive-blank-lines = 1
max-diagnostics = 1000

[resources]
include = true
roots = ["docs"]
max-files = 1000
max-total-bytes = 52428800
max-resource-bytes = 10485760

[workspace.scan]
exclude = ["**/generated"]

[local-targets]
enabled = true
project-root = "docs"

[format]
newline = "lf"
final-newline = true
max-consecutive-blank-lines = 1

[html]
complete = true
stylesheet-files = ["styles/manual.css"]
stylesheet-urls = ["https://example.com/manual.css"]
roles = ["definition", "theorem"]
----

[#configuration-items]
== 主な設定項目

[cols="2,2,3",options="header"]
|===
|項目
|設定できる値
|用途

|``schema-version``
|``2``
|使用する設定形式の版を指定します。省略できません。

|``analysis.syntax-mode``
|``permissive``または``strict``（既定値は``permissive``）
|構文の判定方法を指定します。

|``analysis.attributes.<NAME>.value``
|任意の文字列
|文書属性``<NAME>``の値を指定します。文書内では上書きできません。

|``analysis.attributes.<NAME>.unset``
|``true``
|文書属性``<NAME>``を未設定として扱います。文書内では設定できません。

|``lint.rules.<CODE>.enabled``
|``true``または``false``（既定値は規則ごとに異なります）
|診断規則を有効性を指定します。``<CODE>``には``adocweave check --list-rules --format json``で表示されるcodeを指定します。

|``lint.rules.<CODE>.severity``
|``error``、``warning``、``information``または``hint``（既定値は規則ごとに異なります）
|診断規則が報告する問題の重要度を指定します。

|``lint.max-line-length``
|1以上の整数（既定値: 100）
|1行の文字数の上限を指定します。

|``lint.max-consecutive-blank-lines``
|1以上の整数（既定値: 2）
|連続できる空行の上限を指定します。

|``lint.max-diagnostics``
|1以上の整数（既定値: 1000）
|1つの文書で報告する診断件数の上限を指定します。

|``resources.include``
|``true``または``false``（既定値は``true``）
|include先を読み込んで展開するかを指定します。

|``resources.roots``
|相対パスの配列（既定値: 空の配列）
|include先として読み込めるディレクトリを追加します。

|``resources.max-files``
|1から10000までの整数（既定値: 10000）
|読み込むファイルの件数を制限します。

|``resources.max-total-bytes``
|1から52428800までの整数（既定値: 52428800）
|1回の処理で読み込むファイルの合計をバイト数で制限します。

|``resources.max-resource-bytes``
|1から10485760までの整数（既定値: 10485760）
|1つのファイルから読み込む量をバイト数で制限します。

|``workspace.scan.exclude``
|パターンの配列（既定値: 空の配列、最大256件）
|Language Serverの初期走査から除外するディレクトリを指定します。
詳細は xref:#workspace-scan[Language Serverの初期走査]を参照してください。

|``local-targets.enabled``
|``true``または``false``（既定値は``false``）
|リンク、文書間参照、画像およびinclude先を確認するかを指定します。

|``local-targets.project-root``
|相対パス
|ローカル参照の確認を許可するディレクトリを指定します。``enabled = true``の場合は必須です。

|``format.newline``
|``lf``または``cr-lf``
|改行形式を指定します。省略すると入力文書の形式を維持します。

|``format.final-newline``
|``true``または``false``
|末尾改行の有無を指定します。省略すると入力文書の状態を維持します。

|``format.max-consecutive-blank-lines``
|1以上の整数（既定値: 1）
|整形後に連続できる空行の上限を指定します。

|``html.complete``
|``true``または``false``（既定値は``false``）
|完全なHTML文書を出力するかを指定します。

|``html.stylesheet-files``
|相対パスの配列（既定値: 空の配列）
|HTMLへ埋め込むスタイルシートを指定します。

|``html.stylesheet-urls``
|``http``または``https``のURLの配列（既定値: 空の配列）
|HTMLから参照するスタイルシートを指定します。

|``html.roles``
|role名の配列（既定値: 空の配列）
|HTML出力へ残すブロックのroleを指定します。
|===

=== 診断規則の設定

``lint.rules.<CODE>``の``<CODE>``は設定値ではなく、設定する診断規則のcodeを表します。
例えば``macro-boundary``を有効にし、問題をエラーとして報告する場合は次のように指定します。

[source,toml]
----
[lint.rules.macro-boundary]
enabled = true
severity = "error"
----

``[lint.rules.macro-boundary]``は設定する規則、``enabled``は規則の有効/無効、
``severity``は問題の重要度を表します。
``enabled``または``severity``を省略すると、その規則の既定値を使用します。
指定できるcodeと既定値は次のコマンドで確認できます。

[source,console]
----
adocweave check --list-rules --format json
----

設定例の``analysis.attributes.release``は、文書属性``release``の値を``draft``にします。
``analysis.attributes.private``は、文書属性``private``を未設定として扱います。
1つの文書属性に``value``と``unset = true``を同時に指定できません。
``config show``は属性値を表示せず、設定済みか未設定かだけを表示します。

``html.roles``に指定したroleは、HTMLで``role-<name>``というclass属性の値になります。
指定していないroleは出力しません。
名前にはASCIIの英字、数字、``-``および``_``を使用できます。

``resources``の上限は組込み上限以下に設定してください。``roots``、``project-root``およびスタイルシートの
ファイルは、設定ファイルがあるディレクトリ内の相対パスで指定します。ネットワーク上のinclude先は指定できません。
一度の処理で読み込み元として扱えるディレクトリは128件までです。多数のディレクトリを許可する場合は、
それらを含む上位ディレクトリを指定してください。

[#workspace-scan]
== Language Serverの初期走査

``workspace.scan.exclude``には、初期走査から除外するディレクトリのパターンを指定します。
次のパターンは常に適用されるため、設定ファイルへ記載する必要はありません。

[source,toml]
----
exclude = ["**/.git", "**/.venv", "**/node_modules", "**/target"]
----

設定したパターンは、この4件へ追加されます。空のリストを指定しても、組込みパターンは解除されません。
実際に適用されるパターンは``adocweave config show``で確認できます。

パターンはワークスペースフォルダからの相対パスと照合し、大文字と小文字を区別します。区切りには``/``を
使用します。``*``と``?``は1つのディレクトリ名の中だけ、``**``は0個以上のディレクトリに一致します。
例えば``target``は直下の``target``だけ、``**/target``はどの深さの``target``にも一致します。

絶対パス、``..``、``\``、空の区間、単独の区間ではない``**``、文字クラス``[]``および選択肢``{}``は
指定できません。1件のパターンは1024文字、全体では4096文字までです。

初期走査は10万件までです。上限に達した場合は、見つかった文書だけを登録してエディタへ警告します。
``resources.max-files``、``resources.max-total-bytes``または``resources.max-resource-bytes``に達した場合も
同様です。開いている文書は引き続き解析され、未登録の文書も開くと解析されます。

除外したディレクトリの中身は走査件数に含めません。除外は初期走査だけに適用されるため、文書を直接開いた場合、
include先として必要になった場合、またはCLIへ入力した場合は通常どおり読み込みます。

ワークスペースフォルダが入れ子の場合、外側の走査では内側のフォルダを調べません。
内側のフォルダは、自身の``workspace.scan.exclude``を使用します。

== JSON Schema

設定のJSON Schemaは link:../../config/adocweave.schema.json[`config/adocweave.schema.json`]です。
項目名、型、列挙値、既定値および項目ごとの上限を確認できます。

``max-resource-bytes``が``max-total-bytes``以下であることと、
除外パターンの合計が4096文字以下であることは、設定の読み込み時に確認します。

== CLIでの使用

通常は設定ファイルを自動で探します。設定ファイルを指定する場合は``--config FILE``、
設定を使用しない場合は``--no-config``を指定します。この2つは同時に指定できません。

[source,console]
----
adocweave config show
adocweave config show --config config/ci.toml
----

``config show``は、実際に使用する設定を表示します。
設定の優先順位は、組込み既定値、プロジェクト設定、コマンドラインオプションの順です。

== Language Serverでの使用

Language Serverは文書ごとに最も近い設定ファイルを使用します。
設定ファイルを作成、変更または削除すると、開いている文書を新しい設定で解析し直します。
設定に誤りがある場合は、修正されるまで、その設定を使用する文書の診断、整形および問い合わせ結果を返しません。

初期走査の除外設定には、ワークスペースフォルダ直下の``.adocweave.toml``だけを使用します。
下位ディレクトリの設定にある``workspace.scan``以外の項目は、文書ごとに通常どおり適用します。

エディタがファイルをワークスペースフォルダとして渡した場合は、そのファイルだけを初期解析の対象にします。
同じディレクトリにあるほかの文書も読み込む場合は、親ディレクトリをワークスペースフォルダとして開いてください。

エディタの``enabledRules``はプロジェクト設定の後に適用します。共有設定を変えずに、エディタごとに追加の
診断規則を有効にできます。
