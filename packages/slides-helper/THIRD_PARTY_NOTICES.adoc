= Third-party notices for @adocweave/slides-helper

This package processes equations and citations in a Node.js process.
It does not bundle dependency implementations into generated browser pages.
The runtime dependencies are installed by npm, with versions and archive integrity recorded in package-lock.json.
License texts and copyright notices are included in the licenses directory.
