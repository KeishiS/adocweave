研究発表スライドの説明用の例

以下の数値は架空のもので、実測結果ではありません。

== 研究の問い

説明文に見出しを付けると、必要な情報を短い時間で見つけられるでしょうか。

[%step]
* 対象：説明文から指定された情報を探す作業
* 仮定：見出しが、読む場所を選ぶ手掛かりになる
* 比較：見出しの有無による所要時間と誤答数の違い

[#method.columns]
== 手法

[.column]
--
*比較条件*

* 画面A：見出しなし
* 画面B：見出しあり
* 説明文の内容と文字サイズは同じ
--

[.column]
--
*測定の手順*

. 6人が両方の画面で情報を探す
. 画面を使う順番を入れ替える
. 所要時間と誤答数を記録する
--

[.notes]
--
これは研究計画と発表方法を説明するための例です。実験を実施したという意味ではありません。
--

[#results]
== 結果の例

<<method,比較の手順>>に沿って得たと仮定する、架空の数値です。

[cols="2,2,2",options="header"]
|===
|条件 |所要時間の中央値 |誤答数

|画面A：見出しなし |42秒 |2件
|画面B：見出しあり |31秒 |1件
|===

この例では、画面Bの所要時間が短くなっています。 footnote:[中央値は、値を小さい順に並べたときの中央の値です。個数が偶数の場合は中央の2値の平均を使います。]

== まとめ

* 結果の要点：<<results,架空の数値>>では、画面Bの所要時間と誤答数が小さい
* 考察：見出しが探索を助ける可能性はあるが、この例から効果は判断できない
* 次の検証：実際の参加者を募り、文章の難しさや慣れの影響も調べる
