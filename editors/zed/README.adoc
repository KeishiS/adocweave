= Zed開発用拡張

このディレクトリはZedが読み込む拡張のrootです。``extension.toml``、Rust製WebAssemblyアダプターおよび
AsciiDoc言語設定を保持します。拡張の責務とLanguage Serverへの依存方向は
xref:../../docs/developer-guide/architecture.adoc#component-boundaries[アーキテクチャ]を参照してください。

開発版の構築、導入、動作確認および削除は
xref:../../docs/developer-guide/zed-development.adoc[Zedへ開発版を導入する]を参照してください。
利用者がLanguage Serverを導入して選択する方法は
xref:../../docs/user-guide/release-installation.adoc#zed-installation[Zedへの導入]を参照してください。

基本的な構文色付けは``languages/asciidoc``と``languages/asciidoc_inline``のTree-sitter queryが担当します。
Semantic Tokensはリンク、参照およびanchorなどの意味的な情報を補い、基本色付けの代わりにはなりません。
