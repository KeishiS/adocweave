# Changelog

All notable changes to the AdocWeave Zed extension are documented here.

## [0.55.0]

- Prepared the extension for submission to the official Zed extension registry.
- Focused this extension on Language Server integration and reused the existing
  `AsciiDoc` extension for language recognition and syntax highlighting.
- Made the extension version independent from the native AdocWeave version.
- Simplified automatic Language Server download to the latest stable native release.
- Standardized all user-facing extension text in English.
