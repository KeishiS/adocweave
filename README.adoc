AdocWeaveは、AsciiDoc文書の確認、整形、HTML変換を行うRust製ツールです。
コマンドライン、WebAssembly、Language Serverを提供します。

== 主な機能

* AsciiDocからHTMLへの変換
* AsciiDocファイルの整形
* VS CodeとZedでの診断、移動および補完
* ブラウザとNode.jsで利用できるWebAssemblyライブラリ
* textlintによるAsciiDoc文書の検査

AdocWeaveはAsciiDocの全機能を実装していません。対応状況は
xref:docs/user-guide/syntax-support.adoc[対応している書式]、差異と制約は
xref:docs/user-guide/compatibility.adoc[AsciiDocとの互換性]を参照してください。

== インストール

利用する環境に応じた導入方法は、xref:docs/user-guide/release-installation.adoc[インストールと更新]にまとめています。

* コマンドラインとNix
* VS CodeとZed
* WebAssemblyライブラリ
* textlint用Processor

== 基本的な使い方

[source,console]
----
# HTMLへ変換する
adocweave convert manual.adoc > manual.html

# CIでディレクトリ全体を確認する
adocweave check --fail-on warning --format github --summary docs

# 整形が必要か確認する
adocweave format --check docs

# 差分を確認してから整形する
adocweave format --diff docs
adocweave format --write docs
----

全オプション、標準入力および``include::``の扱いは、
xref:docs/user-guide/command-line.adoc[コマンドライン]を参照してください。
